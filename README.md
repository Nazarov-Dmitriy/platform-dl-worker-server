# platform-dl-worker-server

Внешний сервис обработки для нескольких сайтов. Работает на компьютере или отдельном
сервере. Владелец сервиса управляет доступом сайтов, операциями, очередью и ресурсами машины.

## Состояние

Код не начат. Решения пересмотрены 2026-10-12: сайт обращается к сервису по его адресу,
передаёт выданный сервисом токен и отправляет задание одним запросом приёма.
Прежняя схема исходящих claim/heartbeat обработчика отменена.

- [Задачи](docs/future-tasks.md).
- [План](docs/plan/worker-plan.md).
- [Согласованные решения и вопросы следующего обсуждения](docs/plan/site-connections-discussion.md).
- Клиент сайта и контракт: ../serverBreasts/docs/instruction/worker-jobs-api.md.
- Интерфейс сайта: ../front/docs/plan/media-workers-plan.md.

У сервиса будет собственная панель: подключения сайтов, токены, разрешённые операции,
квоты, приоритеты, состояние задач и машины. Админка сайта хранит только подключение,
выбор доступных операций и настройку собственного резерва.

Node / TypeScript и нативный процесс — исходный ориентир. Сеть / HTTPS, панель,
хранение очереди и идемпотентность обсуждаются до реализации.
config.example.json — исторический пример отменённой pull-схемы; текущий формат
конфигурации выбирается после обсуждения и пока не реализован.
