# platform-dl-worker-server

Внешний сервис обработки для нескольких сайтов: аудио в текст, видеоупаковка
и отдельные дорожки субтитров с выбранными языками перевода.
Владелец сервиса управляет подключениями, моделями, приоритетами и ресурсами машины.

Целевые платформы — Windows, macOS и Linux. Предусматривается совместная обработка
на Mac mini M2 A2686 и Windows-компьютере владельца, позднее — на отдельном Linux-сервере.
Диспетчер — отдельный контейнер на сервере: общая очередь, сайты, токены, разрешения,
приоритеты и панель. Медиа обрабатывают подключённые устройства, поддерживающие
исходящее постоянное соединение с диспетчером. Детали протокола ещё спроектировать.
Публичный адрес диспетчера — HTTPS-поддомен существующего домена владельца.
Сервис работает в фоне с отключаемым автозапуском; управление через веб-панель,
аккаунты владельца и операторов. Подключения localhost / LAN / HTTPS.

Сайт обращается к сервису с выданным ему токеном и отправляет задание одним запросом.
Прежняя схема claim/heartbeat отменена.

Очередь с приоритетами без блокировки остальных сайтов, автоматическая параллельность
по ресурсам. Начальные пороги CPU/RAM/занятости диска — 80%, настраиваются.
10 минут — порог проверки задержки, а не автоматического перехода на резерв.
Количество заданий каждого сайта пока не ограничиваем; собираем статистику.

Параметры результата задаёт сайт; сервис выбирает инструменты.
Сохраняем уже реализованную на сайте политику видео без лишнего перекодирования.
Результаты загружаются обработчиком прямо в хранилище по временным ссылкам;
динамический контракт HLS ещё требуется реализовать. Исходник удаляется после
проверки результата или окончательной ошибки по согласованному жизненному циклу.
Рабочая папка по датам, автоматическая очистка, возможность SSD док-станции.

Диспетчер — Go, компактный вариант SQLite + статическая веб-панель;
целевой бюджет 128–256 МБ RAM проверить замерами. Обработчики — Node.js + TypeScript
с отдельными исполнителями FFmpeg и моделей. Канал подключения устройств,
детали хранения и расширения API ещё уточнить.
config.example.json — исторический пример отменённой pull-схемы,
текущий формат конфигурации ещё не реализован.
