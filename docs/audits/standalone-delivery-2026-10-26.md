# Самостоятельная поставка диспетчера — 2026-10-26

Реализованы deploy/standalone и .github/workflows/release.yml.
Готовый архив Linux amd64 включает диспетчер, nginx TLS-прокси, Compose,
установщик, экспорт состояния, идентичность образов и контрольные суммы.
Образы загружаются из архива; исходники и Go на VPS не нужны.

Выбран отдельный порт 8090, адрес — IP или DNS. Первоначальная версия принимала PEM fullchain
и ключ владельца, проверяет срок/имя/пару ключа и TLS-доверие. Частный CA передаётся
явно и должен быть доверенным также на устройствах и бэкенде. Эта граница снята доработкой ниже. Nginx сайта, его .env и firewall не меняются.

Bootstrap поддерживает -password-stdin и -if-needed. Пароль не попадает в аргументы
процесса; файл 600. При повторной установке аккаунт не сбрасывается. Атомарная
замена конфигурации сохраняет прежнего владельца, с отдельной Linux-регрессией.

Экспорт требует обслуживания без назначенных работ, останавливает экземпляр и
сохраняет согласованное полное состояние, сертификаты, конфигурацию и образы.
Старый экземпляр не запускается автоматически. Это перенос той же базы, а не
штатный restore старого снимка: для restore сохраняется существующий механизм epoch.
Произвольное обновление образа поверх базы установщиком запрещено до отдельного
проверенного пути обновления/отката.

Проверки PASS:
- Windows: go test ./..., go vet ./...;
- Docker Linux: go vet и go test -race ./...;
- четыре Linux unit установщика: адреса, сертификат/ключ, владелец/права и symlink;
- ShellCheck трёх .sh;
- новый VPS: localhost:18090, временный сертификат, TLS readiness, Secure cookie,
  настоящий WSS Upgrade 101 с DEVICE-токеном, повторная установка, экспорт/переезд,
  сохранение аккаунта, сессии, устройства, DEVICE-токена и maintenance.

Тестовые контейнеры, база и сертификат удалены. Действующий сайт не переключался.
Публичный production-экземпляр, реальный Mac/Windows, полный медиа-путь и внешние
копии пока не проверены. GitHub workflow добавлен, но из этой сессии не публиковался.
Локальный архив: deploy/releases/worker-server-linux-amd64-<revision>-dirty.tgz;
суффикс dirty указывает на ещё не закоммиченные изменения.

## Автоматические сертификаты — 2026-10-26

Обязательные --cert/--key удалены. Достаточно --host: установщик создаёт CA
(ключ 600 в каталоге 700), сертификат с SAN IP/DNS и публичный device-ca.crt.
Ежедневный systemd timer проверяет продление; за 30 дней до истечения сертификат
перевыпускается с graceful reload собственного nginx. Service/timer проверены
systemd-analyze verify без установки тестового таймера.
CA сохраняется при повторной установке и при переезде/смене IP. Для браузера CA
один раз добавляется в доверенные. Node-обработчик поддерживает tlsCaFile
относительно config.json, включая службу, с rejectUnauthorized=true.

Проверки: пять Linux unit — PASS; автосоздание сертификатов без входных файлов,
TLS/WSS, повторная установка и переезд с сохранением CA, аккаунта, сессии и токена
на localhost:18090 нового VPS — PASS. Processor TypeScript/npm test: 27 PASS,
четыре интеграционных теста пропущены без E2E_DISPATCHER. Рабочие загрузки сайта
не переключались. Готовый архив теперь в deploy/releases/ (игнорируется Git).
