# Этап 3: обработчик и соединение

Дата: 2026-10-13. Реализован Node.js/TypeScript-обработчик и транспорт устройств Go.
Следующий этап — файлы, FFmpeg и полный видеопуть. Соседние приложения и VPS
не менялись; рабочие медиа и production-токены не использовались.

## Результат

- WSS с DEVICE-токеном, проверка сообщений v2 и TLS. Новая сессия закрывает прежнее
  соединение устройства. Job ID и fence проверяются вместе в транзакции.
- Назначение, принятие, статус, продление, отмена/остановка, reconnect.
- Долговечный `protocol.ack` для failed/stopped/decline: миграция 002, дедупликация
  атомарна со сменой статуса, переживает restart, очищается через срок истории.
- Журнал атомарной заменой файла с fsync и повтор неподтверждённых сообщений.
  Одна программа на stateDir; ОС держит блокировку через закрытый loopback-порт.
  Коллизия хеша порта приводит к отказу запуска, а не двум писателям.
- Сроки от отправки запроса, монотонные/календарные часы и запас остановки.
  Отдельный дочерний сторож, остановка собственного дерева на истечении права/потере IPC:
  Windows taskkill, Unix process group. Сохранённые PID не используются.
- Допуск по CPU/RAM/занятости рабочего диска, давлению памяти, резервам и пределу
  параллельности. Исчезновение/подмена рабочего тома блокирует допуск; повторная привязка
  только без незавершённых попыток. GPU/VRAM пока неизвестны, нет GPU-исполнителя.
- Тестовый исполнитель возвращает `TEST_EXECUTOR_ONLY`, не ложный успех.
  По умолчанию выключен; операции пусты до установки настоящего исполнителя.

## Проверки

- Windows: Go tests/vet, контрактный валидатор; 11 Node tests без пропусков, включая локальный сценарий
  двух Node-обработчиков с настоящим Go/SQLite-диспетчером.
- Linux/Docker: Go vet + race tests; 11 Node tests без пропусков, включая полный интеграционный сценарий.
- Go: потеря grant/повтор без продления срока, замена соединения, неверный jobId,
  terminal replay после reconnect/restart, конфликт messageId, атомарность отказа,
  миграция БД этапа 2, TLS Upgrade.
- Node: задержанные/неизвестные grants, сон как скачок часов, зависание event loop,
  аварийное завершение владельца исполнителя, остановка процесса, журнал,
  запрет подмены папки, пороги ресурсов, эксклюзивный запуск.
- Интеграция: два разных одновременных задания, reconnect без нового PID, отмена,
  окончательная ошибка теста, отключение диспетчера, остановка по локальному сроку
  и сохранение сообщения об ошибке.
- npm audit после закрепления исправленных зависимостей: 0 известных уязвимостей.

Снимок нагрузки в интеграции фиксирован тестом. Это проверка протокола/процессов,
не замер пропускной способности. Физический сон Mac и отрыв SSD не проверены: Mac
не подключён. Замена папки и скачки часов не доказывают поведение конкретной док-станции.
FFmpeg/модели, потребление VRAM/подкачки, очистка медиа и публикация — следующие этапы.
