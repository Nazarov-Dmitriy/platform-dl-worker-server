# Доработка сервиса перед интеграцией сайта

Дата: 2026-10-13. Репозиторий worker-server; production, `.env`, бэкенд/фронтенд
сайта не изменялись. Это результат исправлений после исходного readiness-review.

## Исправлено и реализовано

1. Повторные lease.granted при скачивании больше не запускают ту же задачу заново.
   Запуск зависит от отдельного сохранённого started, а не наличия FFmpeg процесса.
2. Распознавание/перевод вынесены в управляемый дочерний процесс и worker thread.
   IPC, heartbeat и renew не блокируются синхронным CLI/inference. Независимый
   watchdog останавливает собственное дерево при expiry, отмене и потере владельца.
   Lease передаётся ребёнку до start; результаты проверяются при действующей аренде.
3. Whisper возвращает настоящий auto-язык и миллисекундные тайминги из JSON.
   Проверяются пустой результат, язык и интервалы. FFmpeg извлекает mono PCM16 16 kHz;
   контролируются длительность и место для WAV.
4. Реальный offline перевод Transformers.js 4.3.1/ONNX CPU, OPUS-MT q8 EN→RU/RU→EN.
   Сохраняются отдельные VTT и исходные тайминги; ошибка одного языка сохраняет видео
   и успешные дорожки. Тестовые пакеты запрещены без allowTestModels.
5. Исправлены неверные SHA-256 и размер Whisper base, неверный SHA small;
   URL закреплены на конкретном HF commit. Base/small объявляют 99 языков,
   не обещают yue из large-v3. Старые известные ошибочные записи и фиктивный
   NLLB-пакет удаляются из каталога при локальной инициализации/обновлении.
6. Загрузчик моделей поддерживает ограниченные перенаправления без HTTPS→HTTP,
   ограничивает поток размером, проверяет хеш, пишет временный файл.
   Многофайловые пакеты проверяются целиком и переключаются атомарно.
   Ошибка переустановки сохраняет прежний пакет; orphan/.part очищаются при старте.
   Проверяются платформа, доступность рабочего диска и исполнителя.
7. FILE и локальный VOD HLS: части скачиваются по отдельным grants, проверяются
   bytes/hash, ссылки плейлистов не могут выходить в сеть или за каталог.
   Неподдерживаемое шифрование/неоднозначный корень возвращают ошибку.
8. Передачи прерываются по отмене; скачивание ограничивается заявленным размером;
   PUT стримится с диска, без загрузки целого видео в RAM. Видео контролирует
   maxOutputBytes во время упаковки. Ошибки ОС превращаются в валидные коды,
   без путей/стеков в протоколе. Terminal сообщение сохраняется до очистки файлов;
   upload.complete и awaitingPublication сохраняются одним журналированием.
9. Настройки панели переживают перезапуск; CPU/RAM/диск имеют независимые пороги.
   Оценка slots учитывает RAM активных моделей. Автозапуск вызывает установщик ОС,
   успех подтверждается после его выполнения. Включение требует файла ключа.
   Исправлены Windows ACL/Unicode/двойная регистрация и PowerShell 5/7,
   Mac LaunchAgents/XML, systemd пути/%. Отключение сохраняет текущий процесс.
10. HTTPS cookie включаются явным -secure-cookies для proxy/Compose;
    произвольный X-Forwarded-Proto не даёт доверия. Nginx metadata 8 MiB согласован
    с Go. Инструкции актуализированы; сохранён opt-in тест настоящих моделей.

## Проверки

- Windows: Go test ./..., Go vet, сборка dispatcher.exe.
- Linux Docker: Go vet + go test -race ./... без ошибок.
- Windows: npm test — 30/30, без skips; реальный FFmpeg и локальный Go dispatcher.
- Linux Docker (Node 22.22.3): npm test — 30/30, без skips; синтаксис shell установщиков прошёл.
- Windows настоящий whisper.cpp v1.7.6 + base: JFK WAV, auto=en,
  распознан текст «ask not what your country…», настоящие интервалы.
- Windows настоящий OPUS-MT/ONNX: EN→RU «Привет, как дела?», RU→EN
  «Hey, how you doing?». Тайминги 1.25–3.75 сохранены. Повторяемый
  scripts/model-smoke.mjs выполнил все три проверки успешно.
- npm install/audit после обновления движка: 0 известных уязвимостей.
- contracts/validate.py: HTTP схемы, fixtures, state traces и lease cases прошли.
- PowerShell установщики разобраны AST без ошибок; shell syntax прошёл в Docker.

Основные regressions: renew до запуска executor, блокирующая речь и expiry,
redirect/неудачная переустановка, превышение размера/abort, безопасный HLS,
сохранение настроек, отдельные пороги и нормализация ошибок. Существующие проверки
дедупликации, конкурентного назначения, fences, публикации, ролей, копий/restore
сохранены и входят в общий прогон.

## Границы проверки и дальнейшая работа

- Бэкенд сайта ещё использует старые endpoints/локальную упаковку/ZIP.
  Следующий пакет: [B1–B5](../plan/site-integration-stage1.md), затем фронтенд
  статусов/дорожек. В этом репозитории изменения сайта не выполнялись.
- Реальный Mac M2, сон/возобновление, внешний SSD и регистрация автозапуска на
  свежих Windows/macOS/Linux требуют аппаратной приёмки. Службы на машине
  разработчика не регистрировались.
- Реальные модели проверены на CPU Windows; Linux автоматические speech tests
  используют явно включённые catalog-test. Нет замера длинных файлов или нагрузки.
  Аппаратные CUDA/Metal/HARDWARE_ALLOWED не объявляются до проверки mapping.
- VOD HLS без шифрования; live HLS и encrypted HLS не поддерживаются.
- Подготовка обновления — maintenance + snapshot + ручная замена образа,
  автоматического доступа контейнера к Docker daemon нет.
- Пакет требует установленного Node/FFmpeg/whisper-cli; внешняя S3-копия требует
  AWS CLI/скрипта хоста и настройки хранилища. Production/TLS/S3 не проверены.
