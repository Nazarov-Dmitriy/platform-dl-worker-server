# Приложение обработчика для macOS

Обновлено: 2026-10-28. Запланировано. Windows 0.8.1 работает; готовая macOS-поставка и ускорение на Mac ещё не приняты.
Родительская задача: [future-tasks.md](../future-tasks.md).

## Этап 1 — согласованный объём

`Приложение обработчика для macOS — этап 1 (диспетчер и приложение)`

- [ ] Собрать самостоятельное приложение .app для Apple Silicon, первым проверить Mac mini M2, 16 ГБ; пользовательский запуск без Node/npm/VS Code.
- [ ] Проверить безопасное хранение токена, HTTPS/WSS, локальные настройки, menu bar, фон, паузу, выход, автозапуск по желанию и восстановление подключения.
- [ ] Подключить и проверить VideoToolbox для видео, Metal для поддерживаемого движка речи и Auto/CPU/GPU; сохранить лимиты параллельности и рабочую папку как настройки самого приложения.

## Этап 2 — интерфейс и поставка

`Приложение обработчика для macOS — этап 2 (интерфейс и поставка)`

- [ ] Добавить понятные настройки/состояния в соответствующую панель или приложение, не выдавать черновик за выпущенную функцию.
- [ ] Выпустить проверенную сборку только после профильных проверок и зафиксировать фактическую версию.
