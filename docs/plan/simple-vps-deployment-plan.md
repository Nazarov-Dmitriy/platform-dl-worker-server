## Этап 1 — самодостаточный контейнер

`Медиа: единый сервис обработки v2 — этап 1 (самодостаточный контейнер)`

- [x] Один Go-контейнер: автоматический CA, серверный сертификат, HTTPS/WSS и продление в процессе.
- [x] Bootstrap использует пароль, выбранный в установщике; временный файл 600 удаляется после настройки, существующий аккаунт не сбрасывается.
- [x] Публичный сертификат скачивается из панели без SSH; приватный ключ не выдаётся.
- [x] Перезапуск, смена адреса и продление сохраняют CA; адрес сохраняется в данных.
- [x] Windows Go tests и Linux vet/race tests PASS; проверены безопасность скачивания и TLS.

## Этап 2 — команда пакета

`Медиа: единый сервис обработки v2 — этап 2 (команда worker install)`

- [x] `sudo bash worker install`: IP, логин, выбранный пароль; видимая папка instance рядом с пакетом.
- [x] Готовый архив содержит один образ; установка из Git автоматически собирает его Docker-ом.
- [x] Команды start/stop/status/logs/where/export; повторная установка сохраняет данные.
- [x] Переезд пакетом сохраняет базу, аккаунты, сессии, CA и токены.
- [x] Три Linux unit, ShellCheck и изолированный VPS smoke: один контейнер, TLS/WSS, кнопка скачивания, повторная установка и переезд — PASS.
- [x] GitHub workflow переключён на новый пакет и его сквозную проверку.
