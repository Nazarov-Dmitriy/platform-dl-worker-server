# Простая установка диспетчера worker-server на VPS

Дата: 2026-10-26. Общая задача: «Медиа: единый сервис обработки v2».
Комплект поставки реализован и проверен; постоянный публичный запуск и подключение
реальных обработчиков остаются открытыми. Адрес может быть IP или DNS, порт — 8090.
Nginx сайта и порты 80/443 не изменяются. Сертификат и ключ создаются автоматически.

## Этап 1 — готовая поставка

`Медиа: единый сервис обработки v2 — этап 1 (готовая поставка диспетчера)`

- [x] Linux Dockerfile, vet и race-тесты проверены.
- [x] Production Compose без build, постоянная папка data, healthcheck и автоперезапуск.
- [x] Архив с обоими готовыми образами: на VPS не нужны Go и реестр образов.
- [x] Версионирование комплекта, отпечатки образов и SHA256SUMS.
- [x] Workflow сборки, сквозной проверки и выпуска архива по тегу worker-v*.
- [ ] Опубликовать изменения и выполнить первый GitHub release (локальный архив уже готов).

## Этап 2 — установка и перенос

`Медиа: единый сервис обработки v2 — этап 2 (установщик диспетчера)`

- [x] Одна команда с --host: CA, сертификат и ключ создаются сами; systemd ежедневно проверяет продление.
- [x] Проверка сертификата, ключа и доверия; TLS/WSS в собственном контейнере.
- [x] Пароль владельца генерируется в файл 600 и передаётся CLI через stdin.
- [x] Повторная установка не сбрасывает аккаунт/токены и сохраняет владельца конфигурации.
- [x] Экспорт полного остановленного состояния и обоих образов для переезда; прежний экземпляр остаётся остановленным.
- [x] На новом VPS проверены TLS/WSS, повторная установка, перенос и сохранение аккаунта/сессии/устройства/токена; тестовый экземпляр удалён.

## Этап 3 — рабочее подключение

`Медиа: единый сервис обработки v2 — этап 3 (запуск и подключение)`

- [ ] Запустить постоянный экземпляр с автоматическим сертификатом и открыть его TCP-порт у провайдера.
- [ ] Подключить реальное устройство Windows/Mac/Linux с DEVICE-токеном.
- [ ] Выдать SITE-токен сайту; проверить отдельный тестовый файл по полной цепочке до включения внешних рабочих загрузок.
- [ ] Настроить внешние копии SQLite; проверить штатный restore отдельно от переноса полной базы.
