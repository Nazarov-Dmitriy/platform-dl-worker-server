- [x] Сохранять репозиторий, имя, WSL-дистрибутив, Linux-папку и включение автозапуска runner в отдельном ci-settings.json.
- [x] Проверять Linux x64, обычного пользователя, Java 21, Docker/Compose/Buildx, Git, shellcheck, gh и вспомогательные инструменты.
- [x] Скачивать официальный runner, проверять SHA-256 до распаковки, не перезаписывать непустую чужую папку.
