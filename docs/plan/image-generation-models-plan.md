# Генерация изображений: каталог моделей и executor

Обновлено: 2026-11-06. Каталог, установка, протокол и executor Q4 реализованы локально. Реальная генерация на весах и замеры памяти ещё не приняты. Интеграция сайта — [API](../generation-api.md).

Родительская задача: [future-tasks.md](../future-tasks.md).

## Цель

Добавить модели генерации трёх уровней и executor для запуска на выбранном воркере. Отдельный план — можно тестировать независимо.

## Задачи

### Этап 1 — каталог и подбор для устройства

Реализовано локально 2026-11-06. Основные предложенные пакеты — FLUX.2 Klein Q4 и Z-Image-Turbo Q4; исходные Safetensors сохранены дополнительно.

- [x] Общий манифест `contracts/generation-catalog.json`: FLUX.2 Klein 4B (лёгкая, 14,9 ГиБ), Z-Image-Turbo (средняя, 30,6 ГиБ), Qwen-Image-2512 (тяжёлая, 53,7 ГиБ).
- [x] Включены текстовые кодировщики, токенизаторы, VAE и конфигурации; зафиксированы ревизии, размеры и SHA-256 всех файлов.
- [x] Каталог диспетчера и встроенный каталог воркера используют один манифест; `purpose: GENERATION`, `executor: diffusers` описывают пакеты для будущего запуска.
- [x] Установка через панель сайта и приложение: проверка диска, прогресс, контроль хешей, сохранение старой установки при неудачном повторе.
- [x] Описание и уровни моделей; подбор для выбранного устройства с RAM/VRAM, ОС и архитектурой. Для Apple Silicon — общая память, для неизвестного GPU — отсутствие подтверждённой совместимости.
- [x] Требования памяти помечены предварительными (`memoryRequirementsVerified: false`); наличие GPU не подтверждает работоспособность движка.
- [x] Q4-модели активируются после проверки файлов и доступности CUDA/Metal; полные diffusers-пакеты пока не активируются. Worker объявляет только активный поддерживаемый профиль.
- [ ] Проверить установку полных пакетов из Hugging Face на реальном воркере. Тесты загрузчика используют маленькие локальные файлы; десятки гигабайт автоматически не скачивались.
- [x] Подготовить Q4-комплекты FLUX.2 Klein 4B (5,06 ГиБ) и Z-Image-Turbo (6,22 ГиБ), включая сжатые текстовые кодировщики и VAE. Реальная генерация и замеры остаются отдельной приёмкой.
- [x] Закреплённый установщик stable-diffusion.cpp: Windows x64/NVIDIA CUDA и Apple Silicon/Metal; проверка SHA-256, прогресс и пробный запуск `--help`. Официальный Mac-бинарник требует macOS 26+.
- [ ] Добавить ручной импорт произвольных пакетов генерации через форму каталога (сейчас доступны пять встроенных пакетов).

Результаты: [подбор моделей](../testing/model-selection.md).

### Этап 2 — executor и протокол генерации

- [x] `generation-child.ts`: запуск stable-diffusion.cpp без shell, прогресс, один PNG, проверка размера и выходного лимита, завершение процесса после задания.
- [x] `agent.ts`: текст без фиктивного source либо один PNG/JPEG-референс для поддерживаемого профиля; обычные загрузка и публикация результата.
- [x] Независимый watchdog, отмена, потеря аренды и остановка нативного процесса.
- [x] Учёт локальных порогов RAM/VRAM и свободного места; diffusion на CUDA/Metal, кодировщик/VAE на CPU.
- [x] Контракты `media.generate`, `GENERATING`, `IMAGE`, дескрипторы параметров и ревизий модели.
- [x] Разрешение генерации в настройках сайта. Список только готовых моделей через `GET /api/v2/site/generation/models`.
- [x] Универсальная маршрутизация по точной модели и профилю, включая модель только на помощнике; без автоматической подмены.
- [x] Тесты диспетчера, исполнения/передачи PNG на тестовом нативном движке и остановки по аренде/отмене. Реальные веса в этих тестах не загружаются.
- [ ] Реальные генерации FLUX.2 Klein Q4 и Z-Image-Turbo Q4 на Windows/NVIDIA и Mac, качество референса, замеры памяти и лимитов.
