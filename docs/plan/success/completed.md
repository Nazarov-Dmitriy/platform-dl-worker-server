## Модели: установка, смена и применение — 2026-11-05

Закрыта по решению владельца. Бэк: установка/активация/удаление моделей, journal с состояниями INSTALLED/ACTIVE, командами MODEL_INSTALL/ACTIVATE/DELETE, БД `model_catalog` + `device_models`. Desktop: полный экран моделей (среда, группы задач, радиокнопки, кнопки, прогресс-бар, статусы, предупреждения). GPU-детекшн (CUDA через `nvidia-smi`, fallback на PowerShell). Probe GPU перед транскрипцией, `GPU_UNAVAILABLE` при провале. Админ-панель: каталог моделей (добавление/удаление). Тесты: `installModel` (скачивание, хеши, откат при сбое), `deleteModel` (санитизация).

- [x] **Бэк / ядро** — [план](../model-management-plan.md).
- [x] **Фронт / панель или приложение** — интерфейс и состояния по [плану](../model-management-plan.md#этап-2--интерфейс-и-поставка).
- [x] **Тестирование / приёмка** — [чеклист](../../testing/model-management.md) закрыт.

## Базовый Windows/видео этап — 2026-10-28

Закрыт по решению владельца. Диспетчер VPS, подключение сайта, сохранение настроек,
Windows-приложение и видеопроцесс работают. Подтверждены два реальных результата:
около 22 МБ за 31 с и 282 МБ за 100 с от постановки до готовности, задания выполнялись параллельно.
worker-v0.1.11 опубликован после релизных проверок; Windows-сборка — 0.8.1.

- [x] **Бэк / ядро** — очередь, передача файлов, публикация, тестовое исключение LAN HTTP и поставка VPS.
- [x] **Фронт / desktop** — Windows: подключение, фон, автозапуск, настройки процессов и прогресс.
- [x] **Тестирование / приёмка** — базовый видеопроцесс принят владельцем. Это не полная приёмка аудио и macOS.

История с прежними отметками: [архив базового этапа](../archive/worker-baseline-2026-10-28.md).
