# Приложение обработчика для Windows и macOS

Обновлено: 2026-10-27. Реализован первый desktop-вариант и собран Windows .exe.
Проверены настоящий WSS с локальным Go-диспетчером, фон, DPAPI-токен и повторный запуск.
Автозапуск Windows реализован: скрытый запуск и автоматическое подключение.
Mac, чистая установка зависимостей и рабочий медиафайл остаются открыты.
Диспетчер на VPS и его веб-панель — отдельная программа, не устанавливаются повторно на ПК.

## Согласованное поведение

Одна оболочка над существующим processor, две поставки: Windows `.exe` и macOS `.app`.
Пользователь сам запускает приложение. Закрытие окна скрывает его в фон, обработка
продолжается. Значок Windows tray / macOS menu bar открывает окно, ставит на паузу,
возобновляет работу и полностью завершает приложение. Автозапуск — выключенная по
умолчанию опция, а не обязательный способ работы. VS Code, терминал и отдельная
установка Node.js для пользователя готового приложения не нужны.
Linux-приложение/служба отложены: в эту задачу не входят.

## Этап 1 — интеграция существующего обработчика

`Приложение обработчика для Windows и macOS — этап 1 (ядро и жизненный цикл)`

- [ ] Выбрать и зафиксировать способ упаковки общей оболочки; проверить совместимость
  Transformers/ONNX Runtime, native dependencies и дочерних исполнителей на Windows x64 / Mac arm64.
- [x] Переиспользовать Agent/Journal/Resources и протокол v2 без второго независимого executor.
- [x] Отделить жизненный цикл окна от Agent; закрытие окна не останавливает работу.
- [ ] Единственный экземпляр, понятное завершение активных попыток и отсутствие осиротевших процессов.
