## Этап 1 — договориться о сервисе и интерфейсе владельца

`Обработчик: каркас, расшифровка, транскодирование — этап 1`

- [ ] Обсудить открытые вопросы из site-connections-discussion.md: сеть, панель,
  подключения сайтов, квоты, очередь, хранение и восстановление.
- [ ] Спроектировать интерфейс владельца: сайты, токены, разрешённые операции,
  нагрузка машины и очереди. Ограничения задаются здесь, а не на сайте.
- [ ] Подтвердить текущий контракт клиента сайта и расширения версий / ошибок.

## Этап 2 — подключения сайтов и надёжный приём задач

`Обработчик: каркас, расшифровка, транскодирование — этап 2`

- [ ] Настройки сайтов, выдача / отзыв / ротация отдельных токенов, ограничения операций.
- [ ] Каталог операций только аутентифицированного сайта.
- [ ] Один запрос атомарно проверяет разрешения / квоты и принимает работу либо отказывает.
- [ ] Долговечная идемпотентность ID, опрос статуса, восстановление после перезапуска.
- [ ] Справедливое распределение ресурсов, общий предел машины и лимиты каждого сайта.
- [ ] Скачивание / запись presigned-файлов, проверка назначений и размеров, безопасная очистка.
- [ ] Локальный журнал, диагностика и интерфейс без утечки секретов между сайтами.

## Этап 3 — расшифровка аудио

`Обработчик: каркас, расшифровка, транскодирование — этап 3`

- [ ] Исполнитель media.transcribe, выбор инструмента и модели на сервисе.
- [ ] Прогресс / результат / устойчивые ошибки для сайта.
- [ ] Замеры русского аудио: качество, память, скорость; лимиты по реальным возможностям машины.

## Этап 4 — видео, запуск и обновление

`Обработчик: каркас, расшифровка, транскодирование — этап 4`

- [ ] media.transcode: согласовать профиль упаковки / outputs сайта и возможности FFmpeg.
- [ ] VideoToolbox на Mac, обычные инструменты на сервере; локальные пределы CPU/RAM/диска.
- [ ] Установка, автозапуск, перезапуск и обновление программы управляются владельцем сервиса.
- [ ] Приёмка нескольких сайтов: один сайт не захватывает очередь и ресурсы остальных.

Node / TypeScript и запуск нативным процессом остаются исходным ориентиром;
сетевую публикацию, устройство панели и долговечную очередь уточнить до кода.
