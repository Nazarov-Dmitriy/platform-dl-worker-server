# Устройства: основные и помощники

Обновлено: 2026-10-29. Локальная логика диспетчера проверена автоматическими тестами; в панели введены названия «Основной» и «Помощник». Визуальная приёмка и выпуск не завершены.
Родительская задача: [future-tasks.md](../future-tasks.md).

## Этап 1 — согласованный объём

`Устройства: основные и помощники — этап 1 (диспетчер и приложение)`

- [x] Сохранять назначенную вручную роль устройства на диспетчере: основной или помощник; без зависимости от ОС. Основных и помощников может быть несколько.
- [x] Отдавать новые задания совместимым основным со свободными слотами и допустимыми ресурсами; помощники подключаются, если подходящие основные заняты, перегружены, на паузе или недоступны.
- [x] Смена роли влияет только на новые назначения. Уже работающие задания не переносить. Одна машина и парк только из помощников продолжают работать; одинаковые роли не должны приводить к дублям.

Реализация использует существующее поле API `priority`: панель сохраняет 100 для основного и 0 для помощника. Существующие числовые приоритеты API сохраняют прежний порядок назначения; положительное значение отображается как «Основной». Новые устройства по умолчанию — помощники. Изменять приложение обработчика для назначения роли не требуется.
