# Субтитры урока: создание, перевод и замена — приёмка

Дата: 2026-11-15. Статус: Worker контракт и VTT-ветка реализованы; ручной прогон SUB-01…10 ждёт Backend/Frontend сайта. Все пункты E2E открыты.
План: [Frontend](../../../LRIGHT/front/docs/plan/lesson-subtitles-management-plan.md), [Backend](../../../LRIGHT/serverBreasts/docs/plan/lesson-subtitles-management-plan.md), [Worker](../plan/lesson-subtitles-management-plan.md).

## Подготовка и учёт

- Роль: администратор или автор с правом менять данный урок; отдельная учётка без такого права для SUB-08.
- Вход: `/admin/courses/{courseId}/edit/lessons/{lessonId}/media`. Пример текущего экрана: `/admin/courses/a77159f6-eb13-4567-908c-7b4a069ed40a/edit/lessons/545664a7-a81c-4e10-9bcf-0b0c7c18145e/media`.
- Данные создавать вручную на отдельном тестовом уроке: короткое видео с русской речью, валидные ru.vtt / en.vtt и SRT, испорченный VTT; сохранить копии исходных дорожек и их идентификаторы. Урок владельца без подготовки не изменять.
- Для переводов нужен доступный воркер и направление ru→en; для негативных сценариев — управляемый отказ перевода и задержка задачи на тестовом стенде. Способ инъекции отказа согласовать при реализации; сейчас не подготовлен.
- Все сценарии кроме просмотра меняют тестовые данные. После каждого восстановить исходные файлы, дождаться завершения/отмены задач; в конце удалить только созданный тестовый урок.
- Ниже — индекс актуальных ручных сценариев SUB-01…10. Исполняемых тестов пока нет; unit и отчёты прогонов добавить при реализации, отсутствие автоматизации не означает PASS.
- Результат прогона: дата, версии трёх сервисов, стенд, ширина, ID, наблюдение, дефект/отчёт. BLOCKED оставлять открытым.

## Позитивные сценарии

- [ ] **SUB-01 — создание из сохранённого видео** (актуален).
  - [ ] **1.** Открыть тестовый урок с готовым видео без дорожек; нажать «Создать субтитры с ИИ», выбрать «Из видео», автоопределение и перевод en; увидеть итоговый состав задания.
  - [ ] **2.** Запустить; дождаться завершения и увидеть ru/en в списке и плеере; убедиться по заданию/логам, что повторное HLS-кодирование не запускалось.
  - [ ] **3.** Перезагрузить страницу; обе дорожки сохранены, видео воспроизводится.
- [ ] **SUB-02 — перевод готовой дорожки** (актуален).
  - [ ] **1.** Оставить ru.vtt и удалить en на тестовом уроке; открыть «Добавить / обновить с ИИ» и выбрать ru как источник; автоопределения нет, ru недоступен среди целей.
  - [ ] **2.** Выбрать en и запустить; дождаться готового en.vtt, исходный ru не изменён; по заданию/логам нет загрузки видео, извлечения аудио, ASR и HLS, работает только перевод.
  - [ ] **3.** Скачать результат: число/порядок реплик, идентификаторы и тайминги соответствуют исходнику; текст переведён, VTT валиден и читается плеером.
- [ ] **SUB-03 — ручная замена русского файла** (актуален).
  - [ ] **1.** При существующих ru/en добавить другой файл с языком ru; увидеть подтверждение с названием языка; отменить — список и серверные файлы прежние.
  - [ ] **2.** Повторить и подтвердить; до общего сохранения серверный ru прежний. Сохранить — активен новый ru, en не изменён, дубля ru нет.
  - [ ] **3.** Повторить с SRT; результат доступен как валидный VTT для плеера и выбора источником перевода.
- [ ] **SUB-04 — подтверждённая замена ИИ** (актуален).
  - [ ] **1.** При ru/en открыть перевод из ru; en помечен существующим и не выбран. Выбрать en и новый поддерживаемый язык; итог различает замену и добавление.
  - [ ] **2.** Отменить подтверждение — задача не создана. Повторить, явно разрешить замену en и запустить; до публикации скачивается старый en.
  - [ ] **3.** Дождаться успеха — en заменён один раз, новый язык добавлен, ru прежний; замена ru вручную сама по себе не запускает новый перевод en.

## Смена состояния и конкуренция

- [ ] **SUB-05 — частичный успех и повтор** (актуален).
  - [ ] **1.** Подготовить два целевых языка и отказ одного; запустить перевод и дождаться частичного завершения: успешный язык опубликован, неуспешный сохранил прежний файл либо отсутствует, если его не было.
  - [ ] **2.** Восстановить воркер и повторить ошибки; обрабатывается только неудачный язык, успешная дорожка не заменяется повторно.
- [ ] **SUB-06 — две вкладки и устаревший результат** (актуален).
  - [ ] **1.** Открыть урок в двух вкладках, запустить задержанный перевод ru→en; во второй вкладке попытаться заменить/удалить ru или en либо создать вторую задачу — сервер отклоняет конфликт; другой язык можно изменить.
  - [ ] **2.** Отменить задачу, заменить en либо видео, затем воспроизвести поздний результат старого задания в контролируемой backend-проверке; он не меняет новые данные и не возвращает удалённую дорожку.
  - [ ] **3.** При автоопределении из видео проверить блокировку изменений всех дорожек; при обнаружении уже существующего ru его файл не заменяется без ранее данного разрешения.
- [ ] **SUB-07 — грязная форма, перезагрузка и отмена** (актуален).
  - [ ] **1.** Добавить несохранённый файл; попытаться начать ИИ — получить предложение сохранить/отменить правки без скрытого сохранения. Отказ оставляет правки на месте.
  - [ ] **2.** Запустить задачу после сохранения; закрыть окно и обновить страницу — задача продолжается и её статус восстановлен. Во время завершения правка другого языка не теряется.
  - [ ] **3.** Запустить повторную задачу и отдельно отменить; старые активные файлы сохранены, поздний callback не публикуется.

## Негативные сценарии и регрессия

- [ ] **SUB-08 — права, валидация и недоступные модели** (актуален).
  - [ ] **1.** Без права редактирования отправить запрос запуска и замены файлов — отказ доступа, данные не изменились; источник другого урока также отклоняется.
  - [ ] **2.** Загрузить испорченный VTT или выбрать неподдерживаемое направление — понятная ошибка, прежняя дорожка доступна, задача не запускается.
  - [ ] **3.** На устройстве с моделью перевода без ASR выполнить SUB-02 успешно; недоступное распознавание не блокирует перевод. При отсутствии перевода ручная загрузка доступна.
- [ ] **SUB-09 — новый файл видео и воспроизведение** (актуален).
  - [ ] **1.** Загрузить новое видео и включить ИИ; задача запускается после сохранения, выбранные языки не теряются, скачивание и выбор дорожки в плеере работают.
  - [ ] **2.** Заменить видео при наличии субтитров; увидеть явный выбор сохранения дорожек, по умолчанию они не переносятся на новый источник. Старый результат задачи к новому видео не применяется.
  - [ ] **3.** Проверить ошибку загрузки/публикации замены: прежний файл доступен; сохранение старого снимка формы не удаляет дорожки, добавленные задачей в другой вкладке.

## Desktop / Mobile

Верстка — страница медиа урока, список дорожек, окно ИИ, подтверждение замены, статусы и ошибки.

- [ ] **SUB-10 — адаптивность и клавиатура** (актуален).
  - [ ] **Desktop, 1440×900.** Открыть окно, выбрать источник и несколько целей, подтвердить замену и закрыть клавишей Escape до запуска; фокус возвращается на кнопку, все подписи/действия доступны с клавиатуры.
  - [ ] **Mobile, 390×844.** Повторить выбор источника/целей и ручную замену; окно прокручивается, нижние действия доступны, горизонтального переполнения нет, состояние задачи видно после закрытия окна.

## Нельзя проверить на текущем этапе

SUB-01…10 на сайте: Backend/Frontend ещё не поставлены. Worker принимает `media.subtitles` с `params.input=vtt`, маршрутизирует на translation-only устройство и не запускает ASR/FFmpeg; автотесты парсера и диспетчера это фиксируют. Способ инъекции отказа для SUB-05: `failTargets` у catalog-test модели перевода. Создание этого чеклиста не подтверждает прохождение сценариев.
