# Приёмка: сборки GitHub из Worker

Дата 2026-10-30. Статус: исходники проверены, живой GitHub runner и готовая поставка не приняты.
План: [github-builds-plan.md](../plan/github-builds-plan.md).

## Автоматические проверки

- [x] Настройки отвергают shell-подстановки, неверные репозитории, Windows-пути и docker-desktop; параметры передаются позиционными аргументами.
- [x] Временный токен передаётся в stdin, отсутствует в аргументах запуска и сохраняемом состоянии Worker.
- [x] Требуются официальный URL пакета и SHA-256; ошибка метаданных прекращает установку.
- [x] Разбитые на chunks сообщения runner обновляют состояние, повторный старт не создаёт процесс, активная сборка запрещает остановку.
- [x] Блокировка операций исключает одновременные установку/регистрацию/запуск.
- [x] Реальная Linux-проверка: запуск, flock против дубля, остановка своей группы, удаление PID-файла, отказ сигналить чужому PID.
- [x] Electron с изолированным профилем и fixture runner: IPC, вкладки, ошибки валидации, очистка поля токена, сохранение без токена, старт/стоп.
- [x] 20 профильных тестов runner/настроек/автозапуска пройдены.

**Верстка — страницы/компоненты:** настройки Worker, вкладка «Сборки GitHub», формы и статусы.

- [x] **Desktop** — Electron 1160 и 620 px: вкладки переключаются, горизонтального переполнения нет, действия доступны.
- [ ] **Mobile** — неприменимо для desktop-приложения (минимальная ширина окна 620 px); мобильная поставка не заявлена.

## Живая приёмка

- [ ] Готовая Windows-сборка обновлена после выхода из прежнего приложения, вкладка доступна по постоянному пути запуска.
- [x] Реальное окружение Worker-CI проходит preflight модуля приложения; официальный runner установлен с SHA-256, Java 21 и Docker Linux проверены.
- [ ] Runner зарегистрирован для нужного репозитория через готовое приложение.
- [ ] GitHub online/idle/busy совпадает с состоянием приложения при реальной сборке.
- [ ] Сохранённое enabled восстанавливает runner после перезапуска Worker; выход во время сборки не обрывает её.
- [ ] Сборка проходит вместе с медиа в бюджетах CPU/RAM, диск и кэши не растут бесконтрольно.
- [ ] Потеря сети/сон/остановка хоста обрабатываются без двойного исполнителя и двойного деплоя.
- [ ] Маршрут сайта и резерв GitHub приняты по [чеклисту сайта](../../../serverBreasts/docs/testing/worker-ci-runner.md).
