# Windows: режимы обработки и ресурсы — 0.8.0

2026-10-27. Две вкладки: подключение / обработка и ресурсы. Независимые videoMode/audioMode: auto/cpu/gpu, по умолчанию auto. Параллельность применяется без отключения, локальные значения не перезаписываются CONFIGURE сервера. Режимы и cpuThreads фиксируются для каждого нового задания.

CPU-бюджет делится на настроенную параллельность; число допущенных заданий ограничено бюджетом. FFmpeg получает ограничения потоков декодирования/кодирования и один поток фильтров; приоритет снижен. Это не жёсткая процентная квота Windows и не лимит для всех потоков сторонних библиотек.

Видео GPU использует NVIDIA NVENC на Windows. Авто проверяет кодировщик синтетическим кадром; если он недоступен, выбирает libx264. X264_EXACT не подменяется: новые задания сайта используют HARDWARE_ALLOWED. GPU-only при недоступном устройстве/несовместимом профиле возвращает явную ошибку.

Речь: whisper.cpp auto использует доступный backend; cpu добавляет -ng и лимит потоков. gpu проверяет реальную инициализацию GPU коротким запуском перед распознаванием. Подготовка WAV остаётся CPU. Сам GPU-движок и модели должны быть установлены; сборка whisper.cpp с CUDA на этом Windows ещё не проверена. Перевод через transformers-js остаётся CPU.
