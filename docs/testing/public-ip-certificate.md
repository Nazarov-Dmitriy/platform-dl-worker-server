# Let’s Encrypt для IP

Реализация 2026-10-27. Публичный IPv4, короткий сертификат shortlived.

## Проверено

- Go: цепочка доверия и соответствие IP, повреждённая замена не меняет активный TLS.
- Linux: 17 тестов установщика/обновлятора/сертификатов, включая staging без активации,
  отказ выпуска с сохранением прежнего сертификата, приватные права ключа и защиту от symlink.
- Processor: 28 тестов PASS, 4 интеграционных пропущены без локального диспетчера.
- Windows: собрана отдельная папка public-certificate, работающий exe не заменялся.

## Требует приёмки

- Настоящий staging и production выпуск на VPS, проверка продления Certbot.
- Публичная цепочка из Java сайта и WSS Windows/Mac; работа после перезапуска службы.
- Desktop/Mobile: кнопка и состояние сертификата в разделе «Обновления».
