# Приёмка: Генерация изображений — VRAM

Статус 2026-11-05: не пройдена. [План](../plan/vram-detection-plan.md).

## Поведение

- [ ] На ПК с GPU — определяется CUDA, отправляется total VRAM.
- [ ] На Mac Mini — определяется CPU, VRAM = 0.
- [ ] VRAM отображается в панели устройств рядом с RAM.

## Права и оформление

- [ ] **Desktop** — поля VRAM читаемы.
- [ ] **Mobile** — веб-панель устройств показывает VRAM.
