# Локальная рабочая папка устройства

2026-10-27. Панель больше не редактирует workDirectory: папка выбирается только
в приложении Windows/Mac. CONFIGURE не требует путь, поэтому нагрузку и число
заданий можно изменять независимо от локального диска. Новое приложение игнорирует
старое поле workDirectory в командах и сохранённых удалённых настройках.

Совместимость: установить приложение 0.7.3 перед применением настроек без пути;
старое приложение требует workDirectory и не умеет принимать такую команду.
Старое поле остаётся допустимым в схеме только для перехода со старых команд.
