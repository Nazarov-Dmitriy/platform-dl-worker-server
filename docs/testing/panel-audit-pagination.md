# Последние задания и журнал

2026-10-27. Последние задания запрашиваются ORDER BY seq DESC, limit=10. API сайта с прежним курсором не менялся. Журнал владельца получает keyset-пагинацию по seq DESC, 20 строк на страницу и фильтры kind/principalId/jobId/from/to/errorsOnly. Даты передаются в UTC. Фильтры сохраняются при переходе между страницами, изменение формы применяется кнопкой.

Обычные события переведены на русский. У ошибок доступны Подробнее: объяснение, публичный код и сообщение ошибки задания, ID задания. В журнал не передаются manifest, ссылки или токены. Участник отображается именем; История фильтрует события по ID. Для старых событий без сохранившегося задания причина может быть недоступна.

- Go ./...: PASS, включая границы страниц, дату/участника/ошибки, подробности и десять новых заданий.
- Изолированный браузер: русские события, раскрытие WAIT_TIMEOUT, назад/далее, только ошибки, десять новых заданий, отсутствие JS ошибок — PASS.
