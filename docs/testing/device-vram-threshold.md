# Порог VRAM и пояснения устройств

Проверено локально 2026-11-06. Обновление установленного приложения отложено пользователем.

- В настройках устройства есть `vramThresholdPercent`, от 1 до 80%, по умолчанию 80%.
  Отсутствующее поле в прежних настройках трактуется как 80%.
- Поле проходит через панель, JSON Schema, сохранённые настройки и конфигурацию воркера.
  Значение восстанавливается при перезапуске.
- При измеренной загрузке VRAM, равной порогу или выше, `availableSlots` становится 0.
  Текущие задания не прерываются. При снижении загрузки приём возобновляется.
- Без измерения VRAM этот порог не применяется. На Apple Silicon сохраняется
  контроль общей RAM. Для применения ограничения нужен обновлённый воркер.
- Пояснение роли находится под селектом и связано с ним через `aria-describedby`.
- У заблокированных кнопок установки движка генерации, видео и распознавания
  видна причина без наведения мышью. Для запущенного обработчика подсказка
  направляет в «К заданиям» и поясняет, что закрывать приложение не нужно.
  При остановке, установке или другом занятом состоянии показана соответствующая причина.

Проверки: сборка TypeScript, три целевых теста порогов/восстановления настроек,
тесты диспетчера, проверка контрактов и браузерная проверка — PASS.
Браузерная проверка подтверждает отправку VRAM=70, положение пояснения под
селектом и исчезновение причины блокировки после остановки обработчика.
