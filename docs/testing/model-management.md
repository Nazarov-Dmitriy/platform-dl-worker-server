# Приёмка: Модели: установка, смена и применение

Статус 2026-11-05: пройдена. [План](../plan/model-management-plan.md).

## Поведение и регрессия

- [x] На чистом устройстве модель устанавливается с понятным статусом, активируется и используется реальным заданием.
- [x] Смена модели действует на новые задания, сохраняется после перезапуска; активная работа защищена от удаления используемых файлов.
- [x] Сбой скачивания, неверная версия, нехватка места и несовместимое ускорение показаны с причиной; рабочая модель не теряется.
- [x] Каталог возможностей сервиса отражает фактическую готовность и поддерживаемые языки.

## Права и оформление

- [x] Недостаточные права и ошибки сервиса не скрываются как успешное сохранение; токены и подписанные URL не раскрываются в журнале.
- [x] **Desktop** — поля, статусы, ошибки и основные действия соответствующей панели/приложения читаемы и доступны.
- [x] **Mobile** — веб-панель: изменение настройки и просмотр результата доступны без перекрытий; нативный desktop-интерфейс сюда не входит.

Результаты, версии и стенд записать при прогоне; автоматическое покрытие этой задачи пока не заявлено.
