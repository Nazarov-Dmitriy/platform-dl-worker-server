# Подбор моделей для устройства

Проверено локально: 2026-11-06. На действующий сервер изменения не выкладывались.

В панели «Модели» выбирается конкретное устройство. Показаны GPU, ОС, архитектура,
общий и свободный объём памяти. На Apple Silicon GPU использует общую память;
неизвестный ускоритель и старые/offline-воркеры не получают подтверждение совместимости.
Занятая сейчас память отличается от недостаточного общего объёма.

В таблице устройств сохранена одна колонка **CPU / RAM / VRAM** с тремя
индикаторами друг под другом. VRAM переводится из байтов в ГиБ (подпись интерфейса — ГБ).
Для NVIDIA имя и память берутся от одного адаптера (первый в `nvidia-smi`),
встроенная AMD не смешивается с памятью NVIDIA. Выбор между несколькими дискретными
GPU пока не реализован.

Добавлены три скачиваемых пакета: FLUX.2 Klein 4B, Z-Image-Turbo и Qwen-Image-2512.
Это полные исходные Safetensors, включая дополнительные компоненты, не сжатые GGUF.
Метаданные файлов проверены по публичному API Hugging Face и небольшим конфигурациям;
веса целиком не скачивались. Ревизии, размеры и SHA-256 находятся в
`contracts/generation-catalog.json`. Ориентиры RAM/VRAM не являются результатами
измерений: все пакеты отмечены `memoryRequirementsVerified: false`.

Источники:

- [FLUX.2 Klein 4B](https://huggingface.co/black-forest-labs/FLUX.2-klein-4B)
- [Z-Image-Turbo](https://huggingface.co/Tongyi-MAI/Z-Image-Turbo)
- [Qwen-Image-2512](https://huggingface.co/Qwen/Qwen-Image-2512)

Генерация не реализована: пакеты устанавливаются, но активация завершается
`EXECUTOR_UNAVAILABLE`, возможность `media.generate` не объявляется.
Оценка ресурсов не заменяет проверку реального движка.

Проверки:

- `go test ./internal/dispatcher ./panel` — PASS, включая получение расширенного каталога по WSS.
- `python contracts/validate.py` — PASS.
- `npm test` с локальным диспетчером — PASS, 42 теста, без пропусков.
- `node scripts/model-compatibility.test.cjs` — PASS: CUDA, общая память Mac,
  занятая память, неизвестные устройства, неподдерживаемые платформы.
- Установка маленького локального пакета генерации, контроль SHA-256,
  сохранность прежней установки при повреждённом повторе, запрет активации — PASS.
- `node scripts/model-selection-ui.cjs` — PASS: сайт, desktop, mobile,
  отправка команды установки выбранному устройству, переключение Windows/Mac,
  одна колонка ресурсов. Используются тестовые данные, без действующего аккаунта.
