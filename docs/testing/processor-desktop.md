# Приёмка приложения обработчика Windows/macOS

Статус 2026-10-27: первый GUI и Windows .exe реализованы и проверены на изолированном
локальном Go-диспетчере с проверяемым TLS. Полная приёмка остаётся открытой; Mac не проверен.

Экраны/компоненты: подключение, статус, рабочая папка/ресурсы, tray/menu bar, выход.

- [x] **Desktop Windows** — запуск `.exe` без Node/npm/VS Code; подключение и управление доступны.
- [ ] **Desktop macOS** — запуск `.app` на Mac arm64; menu bar и закрытие окна сохраняют обработку.
- [ ] **Mobile** — не применяется к нативному приложению; адаптация веб-панели не часть задачи.
- [x] Закрытие окна скрывает программу; соединение сохраняется; после полного выхода сохранёнными настройками можно подключиться повторно.
- [ ] Пауза прекращает новые назначения; явный выход завершает/согласует попытки и дочерние процессы.
- [ ] Автозапуск выключен по умолчанию, включается/отключается настройкой; старый OS-автозапуск не дублирует программу.
- [ ] Неверные DEVICE-токен/CA, недоступный сервер и переподключение показывают понятный статус без утечки секретов.
- [ ] Рабочий диск отсутствует/сменён — безопасная остановка; состояние/модели сохраняются между запусками.
- [ ] Настоящее задание на Windows и Mac, совместная работа без дублей, загрузка/публикация результата.
- [ ] Установка и обновление приложения сохраняют подключение и журнал; подписи и ограничения платформ проверены на реальных ОС.

## Главный экран — 2026-10-27

Главный экран показывает число активных заданий и состояние ожидания/паузы/подключения.
Настройки подключения и автозапуска открываются отдельно. Общая очередь остаётся в панели диспетчера.
Проверено в упакованном Electron: старт на главном экране, переход в настройки и обратно,
состояние ожидания без активных заданий, скрытие в трей и полный выход — PASS.
