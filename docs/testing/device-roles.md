# Приёмка: Устройства: основные и помощники

Статус 2026-10-28: не пройдена. [План](../plan/device-roles-plan.md).

## Поведение и регрессия

- [ ] Несколько основных и помощников: при свободном основном помощник не забирает подходящую работу.
- [ ] Основные заняты/на паузе/перегружены/отключены — помощник получает задание; после освобождения основные снова получают новые задания.
- [ ] Несовместимый основной не блокирует совместимого помощника; одна машина работает самостоятельно.
- [ ] Роль меняется и сохраняется после перезапуска, активная работа не прерывается; конкурентные запросы не создают дублей.

## Права и оформление

- [ ] Недостаточные права и ошибки сервиса не скрываются как успешное сохранение; токены и подписанные URL не раскрываются в журнале.
- [ ] **Desktop** — поля, статусы, ошибки и основные действия соответствующей панели/приложения читаемы и доступны.
- [ ] **Mobile** — веб-панель: изменение настройки и просмотр результата доступны без перекрытий; нативный desktop-интерфейс сюда не входит.

Результаты, версии и стенд записать при прогоне; автоматическое покрытие этой задачи пока не заявлено.
