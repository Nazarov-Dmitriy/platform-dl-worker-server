## Поведение и регрессия

- [x] Несколько основных и помощников: при свободном основном помощник не забирает подходящую работу (локальные тесты).
- [x] Основные заняты/на паузе/перегружены/отключены — помощник получает задание; после освобождения основные снова получают новые задания (локальные тесты).
- [x] Несовместимый основной не блокирует совместимого помощника; одна машина работает самостоятельно (локальные тесты).
- [x] Роль меняется и сохраняется после перезапуска, активная работа не прерывается; конкурентные запросы не создают дублей (локальные тесты).

- [x] Недостаточные права и ошибки сервиса не скрываются как успешное сохранение; смена роли не записывает токены и подписанные URL в журнал. Проверены ответы 403/503 и событие DEVICE_UPDATED (идентификаторы аккаунта/устройства, без тела запроса).
- [x] **Desktop** — поля, статусы, ошибки и основные действия соответствующей панели/приложения читаемы и доступны (Chromium, 1440×960).
- [x] **Mobile** — веб-панель: изменение настройки и просмотр результата доступны без перекрытий; нативный desktop-интерфейс сюда не входит (Chromium, 390×844).
