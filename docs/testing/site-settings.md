# Настройки сайтов

Проверено 2026-10-27.

- Шестерёнка рядом с весом открывает настройки конкретного сайта с названием и ID.
- Форма добавления скрыта до нажатия «Добавить сайт», доступна отмена.
- Выдача SITE-токена: одноразовый показ секрета, подпись сайта и инструкция для подключения.
- Старые токены не отзываются при выдаче нового; удаление сайта отзывает все его токены.
- Удаление требует подтверждения; незавершённые задания блокируют удаление.
- Удалённый сайт скрыт, история сохранена; повторная выдача токена/включение запрещены.

Проверки: `go test ./...` PASS; Chrome на изолированной API-фикстуре — настройки,
открытие/отмена добавления, выдача токена, отмена удаления и подтверждённое удаление PASS.
Рабочие аккаунты и сайты при проверке не изменялись.
