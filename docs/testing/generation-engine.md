# Установка движка генерации

Реализовано локально 2026-11-06. Движок и модели устанавливаются отдельно.
Автоматическая загрузка версий с сервера не добавлялась: список сборок закреплён
в `processor/desktop/generation-engine-manifest.json`.

Выпуск: [stable-diffusion.cpp master-1052-f5df5f8](https://github.com/leejet/stable-diffusion.cpp/releases/tag/master-1052-f5df5f8).

- Windows x64 с NVIDIA: CUDA-сборка и отдельный архив CUDA runtime, вместе 926 745 095 байт.
  Официальный workflow использует CUDA 12.8.1. Проверяется `nvidia-smi`, CPU-сборка
  не подставляется вместо CUDA без сообщения пользователю.
- Mac Apple Silicon: официальный Metal-бинарник, 37 747 681 байт.
  Проверка Mach-O `LC_BUILD_VERSION` в обоих архитектурных срезах подтвердила
  минимум **macOS 26.0**. На старой macOS скачивание блокируется с объяснением.
  На реальном Mac M2 запуск пока не проверен.
- Intel Mac, AMD/Intel GPU на Windows и Linux не получают кнопку автоматической
  установки этого движка. Поддержка этих сборок может быть добавлена отдельно.

Архивы скачиваются по HTTPS и проверяются по размеру и SHA-256 до распаковки.
Windows-распаковщик предварительно проверяет пути ZIP и запрещает симлинки.
DLL размещаются рядом с `sd-cli.exe`. На Mac сохраняется структура архива.
Путь к новой версии сохраняется в настройках только после успешных `--help` и `--list-devices` с ожидаемым CUDA/Metal;
неудачная установка не удаляет прежний движок. Очистка временных каталогов
проверяет, что путь находится внутри `tools/generation`.

В приложении: «Модели» → «Движок генерации изображений» → «Проверить движок» /
«Установить движок». Для установки требуется остановить обработчик.
Показываются скачивание, распаковка и проверка запуска. В конфигурацию воркера
передаётся локальный `stableDiffusion`; сервер не может указать произвольную
программу для запуска через эту настройку.

Проверки:

- `node scripts/generation-engine.test.cjs` — PASS, 6 тестов: выбор сборки,
  несовместимая macOS, хеши, проверка запуска, сохранность старой версии,
  параллельная установка и очистка после ошибки.
- `node scripts/model-selection-ui.cjs` — PASS: установка запрещена при
  работающем обработчике, доступна после остановки, результат проверки показан;
  формат RAM/VRAM `используется/всего`, пять моделей в каталоге.
- `npm test` — PASS, 42 теста, без пропусков.
- `go test ./internal/dispatcher ./panel` и `python contracts/validate.py` — PASS.

Реальная Windows-проверка — PASS: скачаны оба официальных архива, проверены SHA-256, распаковка и запуск `sd-cli --help`; `--list-devices` обнаружил CUDA0 / NVIDIA GeForce RTX 5060 Ti (16 283 МиБ VRAM).

Доступен smoke-скрипт `node scripts/generation-engine-smoke.cjs`: он устанавливает
настоящий закреплённый движок в `bin/generation-engine-smoke` и проверяет `--help`.
Аккаунты, рабочая папка и установленный профиль приложения не изменяются.

Проверка подтверждает запуск программы и обнаружение CUDA/Metal, но не выполнение генерации
с моделью. Поддержка `media.generate`, пробная генерация с выбранной моделью,
измерения памяти и выгрузка после задания ещё не реализованы.
