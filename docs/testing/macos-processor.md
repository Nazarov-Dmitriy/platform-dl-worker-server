# Приёмка: Приложение обработчика для macOS

Статус 2026-10-28: не пройдена. [План](../plan/macos-processor-plan.md).

## Поведение и регрессия

- [ ] На Mac mini M2 запускается готовая .app, подключается с проверяемым сертификатом и выполняет реальное видео до публикации.
- [ ] VideoToolbox подтверждён фактическим кодировщиком; Metal проверен поддерживаемой моделью, неподдерживаемое ускорение не маскируется.
- [ ] Закрытие окна, menu bar, пауза, выход, перезапуск и автозапуск сохраняют согласованное состояние и настройки.
- [ ] Одновременная работа Windows/Mac и роли устройств не приводят к дублям; замерены скорость и память при одном/двух заданиях.

## Права и оформление

- [ ] Недостаточные права и ошибки сервиса не скрываются как успешное сохранение; токены и подписанные URL не раскрываются в журнале.
- [ ] **Desktop macOS** — подключение, настройки, задания, menu bar и завершение доступны на целевом Mac.
- [ ] **Mobile** — не применимо к .app; веб-панель проверяется в задаче ролей устройств.

Результаты, версии и стенд записать при прогоне; автоматическое покрытие этой задачи пока не заявлено.
