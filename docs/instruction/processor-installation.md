# Обработчики Windows, macOS и Linux: требования к установке

Дата: 2026-10-13. План инструкции; пакетов и рабочего CLI ещё нет.
Программа Node.js + TypeScript запускает FFmpeg и совместимые исполнители моделей.
Не требуется устанавливать диспетчер или Docker на каждую машину обработки.

## Общая подготовка

1. Доступ к HTTPS-поддомену диспетчера и хранилищу сайта из сети устройства.
   Обработчик сам устанавливает постоянное исходящее соединение; открывать входящие
   порты на домашнем роутере не требуется.
2. Созданное в панели устройство и его отдельный токен; токен сайта сюда не подходит.
3. Выбранная рабочая папка с правами записи и достаточным запасом под исходник/результат.
   Модели в постоянном подкаталоге, задания в files/YYYY-MM-DD/<attempt-id>;
   попытки разных сайтов/устройств не должны пересекаться по одному внешнему ID.
4. Поддерживаемый Node.js LTS: точную версию фиксирует будущий релиз.
   Для production Node рекомендует Active/Maintenance LTS:
   [официальные сведения](https://nodejs.org/en/about/previous-releases).
   Предпочтительный будущий установщик должен уменьшить число ручных действий,
   способ включения runtime в поставку определить на этапе упаковки.
5. FFmpeg/FFprobe и исполнители моделей с закреплёнными версиями, диагностикой
   совместимости и безопасной передачей аргументов без произвольных команд от сайта.

## Платформенные проверки

| Платформа | Что проверить | Автозапуск |
| --- | --- | --- |
| macOS / Apple Silicon | Архитектура arm64, RAM, давление памяти, доступное видео/модельное ускорение, рабочий том | Планируется launchd; точную область запуска и права оформить в установщике |
| Windows | RAM/VRAM, драйвер GPU и доступность кодировщика, пути/права, остановка дерева процессов | Выбрать службу или задачу ОС, запуск без видимого терминала |
| Linux | Архитектура, права, ускорители/драйверы при наличии, RAM/диск и библиотеки моделей | Планируется systemd либо выбранный эквивалент |

Конкретные модели/движки ещё не выбраны. Нельзя обещать одинаковую скорость и поддержку
ускорения только по ОС; устройства сообщают фактически доступные возможности.

## Первый запуск будущего обработчика

- Проверить версии, характеристики машины, рабочую папку и доступность хранилища.
- Ввести адрес диспетчера и токен устройства; проверить появление в общей панели.
- Установить выбранную совместимую модель из панели: файл скачивается на устройство.
  Проверить описание версии, размер, контрольную сумму и наличие места перед активацией.
- Задать резерв ресурсов, начальные пороги 80% CPU/RAM/занятости диска и ручной
  предел параллельности. Наличие места учитывать также в абсолютных байтах.
- Выполнить тестовый файл, измерить время/память/диск. Проверить одно и несколько
  заданий, подобрать безопасную параллельность по результатам.
- Включить автозапуск по умолчанию с возможностью отключения из панели;
  проверить паузу обработки, restart и восстановление состояния.

## Внешний рабочий SSD и очистка

Исходники, результаты, модели и временные файлы исполнителей направляются на выбранный
диск без промежуточных больших записей на внутренний SSD. Если том отключён,
новые задания приостановлены: не создавать папку с тем же именем на системном диске
под отсутствующим mountpoint. Учитывать идентификатор тома, а не только строку пути.
Системная подкачка ОС — отдельно; перенос рабочей папки не увеличивает RAM.

Завершённые задания очищаются после подтверждения приёма результата сайтом.
Проверка старых дат при смене дня, запуске и ежедневно не удаляет активную работу/
передачу; неизвестные остатки после падения сначала сверяются с диспетчером.
Дата берётся в настроенной зоне устройства, сроки исполнения измеряются отдельно.

При отсутствии продления права исполнения две минуты задача останавливается,
её поздний результат не публикуется. После пробуждения/переподключения сначала сверять
активные попытки, а не запускать все локальные папки заново.

## Артефакты будущей поставки

Пакеты/установщики для каждой ОС, пример локальных настроек, диагностическая команда,
интеграция автозапуска, удаление/обновление без потери моделей и рабочей конфигурации,
пошаговые команды установки. При update закончить работу перед заменой исполнителя,
проверить совместимость протокола и возможность отката.
