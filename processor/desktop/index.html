Инструкция: полная настройка
  1. Токен GitHub (один раз). Создай fine-grained PAT с правом Administration → Read и добавь его в репозиторий как секрет RUNNER_ADMIN_TOKEN: GitHub → аватар → Settings → Developer settings → Fine-grained tokens.
  2. Репозиторий. Впиши тот, который хочешь собирать на этой машине, в формате владелец/репозиторий. У каждой записи — своя папка runner и своё имя.
  3. Нажми «Проверить окружение» — должно показать «готово».
  4. Если пути к диску WSL не совпадают, сверху появится предупреждение и кнопка «Обновить путь» рядом с проверкой окружения. Runner заново ставить не нужно.
  5. Если runner не установлен — нажми «Установить runner».
  6. Временный токен. В GitHub открой репозиторий → Settings → Actions → Runners → New self-hosted runner → ОС Linux, x64 → скопируй значение после --token.
  7. Вставь токен в поле «Временный токен регистрации» и нажми «Зарегистрировать runner».
  8. Нажми «Сохранить», затем «Запустить сборки» — появится «Готов принимать сборки GitHub».

Сервер и устройство

В панели Worker откройте «Устройства», добавьте этот компьютер и выдайте ему токен.

Обработка и ресурсы

Бюджет делится между параллельными заданиями. Это ограничение потоков, а не точный процент CPU. При работе на видеокарте CPU тоже используется.

Параллельность меняется сразу. Режимы и CPU-потоки применяются к новым заданиям; текущие продолжают работу.

Видео

Авто использует NVIDIA NVENC, если он доступен. Старые задания с обязательным CPU-профилем выполняются на CPU.

Распознавание речи

Авто использует ускорение установленного движка. Для GeForce нужна сборка whisper.cpp с CUDA. Подготовка аудиофайла выполняется на CPU.

Генерация изображений

Авто использует NVIDIA CUDA на Windows или Metal на Mac, при отсутствии ускорителя — CPU. «Видеокарта» требует доступного ускорителя. В этом режиме текстовый кодировщик и VAE работают на CPU. «Процессор» использует RAM и может работать значительно медленнее. Движок и рабочая Q4-модель выбираются в разделе «Модели».
