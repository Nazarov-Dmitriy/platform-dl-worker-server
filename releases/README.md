# Готовые приложения Worker

Все готовые сборки находятся только в корневой папке `releases/`.

- Windows: `windows/win-unpacked/Worker Processor.exe` — постоянный путь запуска без установки. Установщик `.exe` после `desktop:dist` лежит в `windows/`.
- macOS: готовый `.dmg` после сборки на Mac лежит в `macos/`.
- Linux: готовый `.AppImage` после сборки на Linux лежит в `linux/`.
- Пакет диспетчера для Linux: `linux/server/` (это сервер, а не приложение рабочего компьютера).

Сборка из `processor/`: `npm run desktop:pack` (папка приложения) или `npm run desktop:dist` (установщик). Команды автоматически выбирают папку текущей ОС и обновляют её. Перед обновлением закройте Worker через «Выйти».

Windows, macOS и Linux собираются и проверяются на соответствующей ОС. Наличие папки не означает, что сборка для неё уже сделана. Исходники остаются в `processor/`, в `releases/` находятся результаты сборки.

Не создавать сборки в `processor/desktop-release` или подпапках с названиями доработок. Для обычного запуска Windows всегда использовать указанный постоянный путь.
